# FRAGZONE — устаревшая инструкция 2FA

Двухфакторная авторизация Google Authenticator удалена из текущей версии FRAGZONE. Этот файл оставлен только для истории.

- Текущий API не использует `TOTP_ENCRYPTION_KEY` и не требует настройки TOTP.
- Не удаляйте и не очищайте старые таблицы/записи TOTP автоматически: они могут понадобиться для аудита или ручного восстановления истории.
- Вход владельца выполняется через `/support/owner.html`, сотрудники входят через `/support/admin.html`.
- Не публикуйте пароли, хеши паролей, сессионные cookie или секреты Cloudflare.
